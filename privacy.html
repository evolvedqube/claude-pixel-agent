Pixel Agents privacy policy

Data collected: none

Connects to: 127.0.0.1 (this Mac only)

Support Stays on your Mac

Pixel Agents doesn’t collect, store or share any personal data. It has no accounts, analytics, ads or tracking, and it can’t send anything over the internet.

Effective 21 October 2026. Applies to Pixel Agents for Mac and its Claude Code plugin.

What the app receives

The Pixel Agents plugin for Claude Code sends updates about your sessions to the app over a local connection on your own Mac (127.0.0.1, port 47290). These updates can include:

  • the session ID, title and working folder
  • the model, effort level and agent type
  • the tool Claude wants to use and its input, such as a command or a file path
  • questions Claude asks you, with their options
  • the first 500 characters of Claude’s last reply, or an error message
  • task progress, subagent count and which terminal app the session runs in

The app uses this only to show your sessions on screen and to send your answer (Allow, Deny or your choice) back to Claude Code.

What the app keeps

Session information

Kept in memory only, never written to disk. It’s removed when a session ends and erased when you quit the app.

Settings

Your choices for Pause notifications and Mute chime, and whether setup has finished, are saved in the app’s sandbox on your Mac. Launch at login is off until you turn it on, and macOS manages it in System Settings › General › Login Items.

Clipboard

The app writes to the clipboard only when you click Copy or Copy session ID. It never reads the clipboard.

What leaves your Mac

Nothing. The app accepts connections only from your own Mac and is built without permission to make outgoing network connections. It contains no third-party code, SDKs or services.

Claude Code itself talks to Anthropic as it always does, under Anthropic’s privacy policy. Pixel Agents doesn’t change what Claude Code sends. If you choose Always allow, Claude Code saves that permission rule in its own settings.

Your choices

Because nothing is collected, there’s nothing to request, export or delete from us. To remove everything from your Mac, quit Pixel Agents, move it to the Bin, and uninstall the plugin with /plugin uninstall pixel-agents@pixel-agents. Saved settings live in ~/Library/Containers/evolvedqube.pixel-agent, which you can delete.

Children

Pixel Agents is a developer tool and isn’t directed at children. It collects no data from anyone.

Changes and contact

If this policy changes, we’ll update this page and its effective date. Questions? Email evolvedqube@gmail.com or open an issue at github.com/evolvedqube/pixel-agents/issues.
