Privacy

Pixel Agents gives each Claude Code session a pixel robot in your menu bar, and brings its permission requests and questions to the notch so you can answer from any app.

Version 2.0. Requires macOS 26.6 or later and Claude Code.

Set up

  1. Open Pixel Agents. The Setup window shows Listening on 127.0.0.1:47290 when it’s ready.
  2. In any Claude Code session, run these two commands to install the plugin: 
    /plugin marketplace add evolvedqube/pixel-agents
/plugin install pixel-agents@pixel-agents
  3. Restart Claude Code sessions that were already running. New sessions appear on their own.

To open Pixel Agents when you log in, turn on Launch at login in the Setup window. Open it any time from the menu bar popover with Setup…

Use it

See your sessions

Click the robot in the menu bar. The office shows up to 8 sessions at their desks, and the list below shows them all with their state: Needs you, Your move, Working or Idle. Click a session for its folder, model, tasks, subagents and last reply.

Answer from the notch

When Claude asks for permission, the island shows the tool and command. Choose Allow, Always allow or Deny. For questions, pick an option or type your own answer. If you don’t answer within about two minutes, the request goes back to your terminal.

Stay focused

Hide takes the island off screen until the next request, or until you click Show requests. Pause notifications sends every request straight to the terminal, with no island and no chime. Mute chime keeps the island but silences it.

Fix a problem

My sessions don’t show up

Make sure Pixel Agents is running and the plugin is installed, then restart the Claude Code session. Sessions started before the plugin was installed don’t send updates.

Setup says port 47290 is already in use

Another app is using the port. Quit it (or a second copy of Pixel Agents), then reopen Pixel Agents.

The island didn’t appear

Check that Pause notifications is off and the island isn’t hidden (click Show requests). The request is still waiting in your terminal either way.

The island says “Answer in terminal”

An MCP server is asking for input. Those can only be answered in the terminal, so switch to it to reply.

A session stays Working when it isn’t

Sessions with no updates for 15 minutes are greyed out as stale, and leave once the session ends.

Uninstall

Remove the plugin in Claude Code:

/plugin uninstall pixel-agents@pixel-agents
/plugin marketplace remove pixel-agents

Then quit Pixel Agents and move it to the Bin. Without the app running, the plugin does nothing and Claude Code works as usual.

Contact us

Report a bug or ask a question

Open an issue at github.com/evolvedqube/pixel-agents/issues, or email evolvedqube@gmail.com. We usually reply within two business days.

Include your macOS version, the Pixel Agents version and what you expected to happen. Please leave out prompts, code and file paths you don’t want to share.
