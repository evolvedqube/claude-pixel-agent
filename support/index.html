Support

Help, troubleshooting, and answers to common questions.

Getting Started

  1. Install Pixel Agent for Claude Code from the Mac App Store and launch it.
  2. On first launch, the app shows a folder picker. Choose your ~/.claude folder so the app can detect Claude Code sessions.
  3. Start a new session in Claude Code. A pixel robot will appear in your Dock representing that session.
  4. Click any robot to see live cost, token counts, working directory, and other session details.
Each robot's appearance is generated from your project's working directory, so different projects always look distinct.

Frequently Asked Questions

What does Pixel Agent for Claude Code do?

It watches your Claude Code session files locally and renders one pixel-art robot per active session in your Dock. Clicking a robot opens a small popover with that session's cost, token usage, duration, and working directory.

Why does the app ask for folder access on first launch?

The app runs in the macOS App Sandbox, which means it can only read files inside folders you explicitly grant it access to. To detect Claude Code sessions, it needs read and write access to your ~/.claude folder.

I clicked "Don't Allow" on the folder picker. How do I retry?

Open the menu-bar icon and choose Grant Folder Access. The folder picker will reappear so you can grant access. Once permission is granted, this menu item disappears.

I don't see any robots in the Dock.

  • Make sure you have granted folder access (see previous answer).
  • Confirm Claude Code is installed and that you have at least one active session running.
  • Quit and relaunch Pixel Agent for Claude Code.
  • If robots still don't appear, please email support with a brief description.

What data does the app collect?

None. The app runs entirely on your Mac with no network access. See the Privacy Policy for full details.

Which macOS versions are supported?

macOS 26.0 (Tahoe) and later, on both Apple Silicon and Intel Macs.

Does the app work without Claude Code installed?

The app launches and runs, but no robots appear because there are no Claude Code sessions to monitor. Install Claude Code from claude.ai/code to start using it.

How do I change which folder the app monitors?

Quit the app, remove its sandbox container, and relaunch to be prompted for the folder again. The container lives at ~/Library/Containers/<app-bundle-id>/. Removing it resets the bookmark and first-launch state.

How do I uninstall the app?

Drag Pixel Agent for Claude Code from /Applications to the Trash. To remove all stored data including the saved folder bookmark, also delete ~/Library/Containers/<app-bundle-id>/.

Will the robots affect my battery?

The app uses adaptive frame rates and pauses animations when your display sleeps or when Low Power Mode is enabled, so battery impact stays minimal even with many sessions.
