Pixel Agent for Claude Code · macOS

Privacy Policy

Effective date: May 2, 2026

Overview

Pixel Agent for Claude Code is a Mac menu-bar utility that shows your active Claude Code sessions as pixel-art robots in the Dock. We've designed it to be as privacy-respecting as possible: the app runs entirely on your Mac, has no network access, and never transmits any data off your device.

Information We Collect

Pixel Agent for Claude Code does not collect, transmit, or share any personal information. It does not contain analytics, tracking, advertising SDKs, or any third-party services.

The app reads a small set of session files generated by Claude Code on your Mac, but only inside a folder that you explicitly grant access to. The data read includes:

  • Session identifier and working-directory path
  • Token counts (input and output)
  • Estimated session cost (USD)
  • Session duration and current model name

This information is rendered locally in the app's popover window and is never sent anywhere.

Local Data Storage

To remember the folder you granted access to between launches, Pixel Agent for Claude Code stores a macOS security-scoped bookmark inside its sandbox container at ~/Library/Containers/<app-bundle-id>/. This bookmark stays on your Mac and is removed automatically when you uninstall the app.

When you grant folder access, the app installs three small hook scripts into your Claude Code folder so it can detect session activity. These scripts run locally on your Mac only and write to disk only inside the folder you selected.

Network Access

Pixel Agent for Claude Code does not request and does not have the macOS network entitlement. It cannot make outbound network connections of any kind. You can verify this by inspecting the app's entitlements or by monitoring its network activity with tools such as Little Snitch.

Third-Party Services

The app does not use any third-party services, SDKs, or external APIs. It does not integrate with iCloud, Apple Sign-In, or any external authentication provider.
